그렉텍(GregTech CEu Modern) 공정 짤 때마다 엑셀이나 외부 계산기 사이트 왔다 갔다 하기 귀찮아서 만든 인게임 노드 그래프 계산기 모드입니다. 팩토리오나 셰이프즈처럼 무한 캔버스에 레시피들을 올려두고 선으로 슥슥 연결하면, 필요한 기계 대수와 전력, 잉여/부족 원자재를 알아서 딱 맞게 계산해 줍니다.

---

## 주요 기능

### 1. 인터랙티브 노드 캔버스 & LOD 렌더링
- 마우스 휠과 드래그로 넓은 화면을 줌/팬하면서 공정을 배치할 수 있습니다.
- 연결선 배치 렌더링 및 원거리 LOD(Level of Detail) 모드를 지원합니다.
- 각 기계 카드에서 처리 시간, 오버클럭 단계, 정확한 EU/t 소모량, 초당 생산/소비량을 바로 확인합니다.
- EMI 완전 연동: 레시피 창에서 바로 보드로 가져오거나, 포트에 마우스 올리고 `R`(레시피) / `U`(사용처) 키를 눌러 바로 찾아볼 수 있습니다.

### 2. 다중 탭 페이지 & 복합 모듈 (Subgraphs)
- **다중 탭 페이지**: 상단 탭 바로 여러 개의 공정 보드를 독립적으로 생성/전환/이름 변경/삭제할 수 있습니다.
- **복합 모듈 (`[📦 모듈]`)**: 복잡한 하위 공정들을 단일 모듈 카드로 패키징하고 펼쳐보기(`⤢`) 할 수 있습니다.

### 3. 스마트 연결선 & 자동 연결
- 출력 포트에서 입력 포트로 마우스를 끌어다 놓으면 파이프라인이 연결됩니다.
- **자동 연결(Auto Connect)** 버튼을 누르면 보드에 올려둔 기계들 중 아이템/유체가 서로 맞는 포트들을 자동으로 이어줍니다.
- **스마트 자동 맞춤 연결 (`Shift + 드래그`)**: 포트끼리 연결할 때 대상 기계의 대수를 정수 올림으로 자동 계산하여 연결합니다.
- 선이나 포트를 우클릭하면 연결이 끊어집니다.

### 4. 기준 레시피 지정 & 정수 올림 비율 맞춤 (Auto Ratio)
- 생산량을 맞추고 싶은 핵심 기계나 최종 완성품을 **기준(Base)**으로 지정할 수 있습니다.
- **비율 맞춤(Auto Ratio)** 버튼을 누르면 지정한 기준 기계의 생산/소비량에 맞춰 연결된 기계 대수를 **정수($1, 2, 3...$) 올림(`Ceiling`)**하여 맞춰줍니다.
- 상류 공급 기계의 생산 속도가 하류 소비 기계의 요구 속도보다 크거나 같도록($\text{Supply} \ge \text{Demand}$) 보장하여 원료 부족 병목을 방지합니다.

### 5. 대형 터빈 / 발전기 연산 & 로터 선택
- **발전기 카드 테마**: 터빈/발전기 카드는 에메랄드 그린 패널(`+EU/t`)로 구별됩니다.
- **3D 로터 선택창 (`[⚙ 220%]` 클릭)**: 그렉텍 기본 로터 및 모드팩 로터를 3D 그리드에서 선택하여 장착할 수 있습니다.
- **정격 병렬 자동 도출**: 로터나 전압 티어를 변경하면 터빈 전압 한계 공식($V_{\text{max}} = V_{\text{holder}} \times \frac{P_{\text{rotor}}}{100}$)에 맞춰 **정격 병렬(Par) 및 발전량을 자동 계산**합니다.

### 6. 병렬 수 직접 입력 & 휠 조절
- **직접 숫자 입력**: `Par` 버튼을 클릭하여 원하는 병렬 수를 키보드로 입력할 수 있습니다.
- **마우스 휠 조절**: `Par` 버튼 위에서 휠을 굴려 2배 증가/감소 또는 `Shift + 휠`로 +1/-1 조절이 가능합니다.

### 7. 인게임 튜토리얼
- 내장된 6단계 대화형 튜토리얼을 통해 기본 사용법을 실습할 수 있습니다.

### 8. 블루프린트 공유 기능
- **공유(Ctrl + C)**: 현재 화면의 배치, 전선, 기계 대수, 티어 설정을 공유 코드(`GTBOARD:...`)로 클립보드에 복사합니다.
- **가져오기(Ctrl + V)**: 공유 코드를 붙여넣어 공정 배치를 불러옵니다.

### 9. 실시간 공정 요약
- 전체 공정 가동 시 총 소모 전력(EU/t)과 최고 요구 전압을 실시간으로 표시합니다.
- 외부 투입 원자재와 최종 생산물/부산물 목록을 요약해 줍니다.

## 조작법 및 단축키

| 기능 | 조작 방법 |
| :--- | :--- |
| 계산기 보드 열기 | 마인크래프트 조작 설정에서 키 지정 |
| 화면 이동 (Pan) | 우클릭 드래그 또는 휠 클릭 드래그 |
| 화면 줌 (Zoom) | 마우스 휠 (커서 중심 줌) |
| 선택 박스 (Marquee) | 빈 공간 클릭 드래그로 사각형 영역 선택 |
| 다중 노드 이동 | 선택된 노드 중 하나를 잡고 드래그하여 일괄 이동 |
| 파이프라인 연결 | 포트 클릭 드래그 -> 대상 포트에 드롭 (출력->입력 또는 입력->출력) |
| **비율 자동 맞춤 연결 (순방향/역방향)** | **Shift + 포트 드래그 -> 대상 포트에 드롭**<br>• 출력->입력: 앞 기계 생산량에 맞춰 뒤 기계 대수 자동 맞춤 (정수 올림)<br>• 입력->출력: 뒤 기계 요구량에 맞춰 앞 기계 대수 자동 맞춤 (정수 올림) |
| 연결 끊기 | 전선이나 포트 소켓 우클릭 |
| 기준 기계 지정 | 노드 상단 `🎯` 아이콘 클릭 |
| 기계 대수 조절 | `[-]` / `[+]` 버튼 클릭, `[/2]` / `[x2]` 배율 클릭, 또는 숫자 박스 직접 클릭 후 타이핑 |
| **병렬(Par) 조절** | **`[Par: 1x]` 클릭 후 직접 숫자 타이핑**, 마우스 휠 굴리기, 우클릭 시 1/2 감소 |
| **터빈 로터 장착** | 발전기 노드의 **`[⚙ 220%]` 로터 버튼 클릭** -> 3D 로터 선택창에서 원하는 로터 클릭 |
| 티어 변경 | `[Tier]` 버튼 클릭 또는 버튼 위에서 마우스 휠 스크롤 |
| 오버클럭 모드 | `[일반 OC]` / `[퍼펙트 OC]` 버튼 클릭 |
| 블루프린트 복사/붙여넣기 | 보드 화면에서 `Ctrl + C` (복사) / `Ctrl + V` (가져오기) |
| EMI 레시피/사용처 조회 | 포트에 마우스 올리고 `R` (레시피) / `U` (사용처) |
| 상단 툴바 / 탭 스크롤 | 툴바 및 탭 바 위에서 마우스 휠 또는 클릭 드래그 |

## 요구 사항

- **마인크래프트**: `1.20.1`
- **모드 로더**: `Forge (47.2.0+)` / `NeoForge`
- **필수 모드**: 없음
- **권장 모드**:
  - [GregTech CEu Modern](https://curseforge.com/minecraft/mc-mods/gregtech-ceu-modern)
  - [EMI](https://curseforge.com/minecraft/mc-mods/emi)

> 참고: 그렉텍에 대한 강제적인 의존성은 없으나, 본 모드는 그렉텍(GTCEu)의 전압 티어와 오버클럭 메커니즘을 기준으로 설계되었으며 GregTech CEu Modern이 설치되지 않은 환경에서는 충분히 테스트되지 않았습니다.

## 소스코드 빌드

```bash
git clone https://github.com/Amvermain/GregTechCalculatorBoard.git
cd GregTechCalculatorBoard
./gradlew build
```
빌드된 파일은 `build/libs/gtcalcboard-1.20.1-1.0.5.jar`에 생성됩니다.
