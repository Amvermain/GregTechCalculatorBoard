## 📌 Maintenance Policy

- When a new minor or major release line begins (such as `v2.3.x` or `v3.0.x`), entries for the previous line (e.g. `v2.2.x`) are moved from the root `CHANGELOG.md` and `CHANGELOG_KR.md` to `docs/changelogs/CHANGELOG_vX.Y.md` and `CHANGELOG_vX.Y_KR.md`.
- The root `CHANGELOG.md` and `CHANGELOG_KR.md` always maintain the active release line and the `[Unreleased]` section.
