## 📌 아카이빙 운영 정책

- 새로운 마이너 또는 메이저 버전 라인(예: `v2.3.x`, `v3.0.x`)이 시작될 때, 직전 마이너 버전 라인(예: `v2.2.x`)의 전체 내역을 루트 `CHANGELOG.md` 및 `CHANGELOG_KR.md`에서 `docs/changelogs/CHANGELOG_vX.Y.md` 및 `CHANGELOG_vX.Y_KR.md`로 분리 이동합니다.
- 프로젝트 루트의 `CHANGELOG.md` 및 `CHANGELOG_KR.md`에는 항상 최신 활성 릴리즈 라인과 `[Unreleased]` 섹션만 유지됩니다.
