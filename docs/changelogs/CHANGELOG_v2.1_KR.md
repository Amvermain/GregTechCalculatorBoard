## [2.1.0] - 2026-09-04

### 신규 기능 (Added)
- **EMI 호버 슬롯 실시간 동기화 하이라이트 (`EmiPreviewWidgetHolder`)**:
  - 레시피 뷰어(EMI) 다이얼로그 내에서 슬롯에 마우스를 올렸을 때, 캔버스 상의 해당 아이템/유체 포트 및 배선을 실시간으로 추적하여 시안색 하이라이트로 동기화 표시하도록 연동했습니다. 이를 통해 복잡한 배선도에서 원료 매칭을 즉각적으로 추적할 수 있습니다.
- **인터랙티브 분기점(Junction) 노드 목표 배치 소요 시간(ET / DT) 계산 및 14단계 튜토리얼 체계 개편**:
  - 온보딩 튜토리얼을 체계적인 14단계 시퀀스(`TutorialStep`, 1~14단계)로 전면 개편하고 코스 구분을 명확히 확립했습니다:
    - **기본 기능 튜토리얼 (1~9단계)**: 5단계(`STEP_5_JUNCTION_ETA`)를 신설하여 초심자 코스에서도 보일러-정션-터빈 배선 직후 분기점 뱃지 클릭을 통한 목표 배치 수량(예: 1,000 mB) 설정과 실시간 예상 생산 완료 소요 시간(`ET: 2.0s`) 계산을 즉시 학습할 수 있도록 배치했습니다. 수량 입력 후 엔터를 누르면 머신 선택기 스텝으로 자동 진행됩니다.
    - **고급 기능 튜토리얼 (10~13단계)**: 12단계(`STEP_12_JUNCTION_SUPPLY`)를 통해 분기점의 외부 공급 모드(무한 공급 ∞, 고정 유량 한도) 설정 및 상류 결핍 격리, 투입 원자재 재고 고갈 시간(`DT: xx.xs`) 등 심화 활용법을 완벽히 마스터할 수 있도록 분리했습니다.
  - 인게임 가이드 다이얼로그(3장 와이어 연결, 8장 단축키 및 조작)에 분기점 노드의 ET/DT 연산 공식 및 인터랙션(좌클릭: 배치 목표량 입력, 우클릭: 공급 모드 설정, Shift+우클릭: 목표량 초기화) 안내를 보강했습니다.

### 개선 및 변경 (Changed & Improved)
- **가상 뷰포트 배율 독립 분리 및 좌표계 정합성 개선**:
  - 보드 전용 가상 뷰포트 배율(`boardGuiScale`) 변경 시 마우스 히트박스 판정, 다이얼로그 드래그 오프셋, 툴바 Scissor 클리핑, 스티커 메모 텍스트 렌더링 좌표가 오차 없이 1:1로 일치하도록 변환 체계를 보강했습니다.
- **4개 국어 다국어 리소스 전수 동기화 (i18n)**:
  - 한국어(`ko_kr`), 영어(`en_us`), 중국어 간체(`zh_cn`), 러시아어(`ru_ru`)의 974개 번역 키를 전수 동기화하여 다국어 환경의 번역 누락을 해소했습니다.

### 버그 수정 (Fixed)
- **공유 기계 풀(Shared Machine Pool) 멀티블록 BOM 자재 중복 집계 결함 수정**:
  - `MultiblockBOMCalculator`에서 공유 기계 풀(`CanvasGroupFrame`) 내 동일 멀티블록 구조체 블록이 각 레시피마다 중복으로 가산되던 계산 결함을 수정했습니다. 개별 레시피 단위가 아니라 공유 풀에 속한 레시피들의 총 시간 점유율을 합산한 뒤 정수 올림(Ceiling Quantization)된 실제 물리 기계 대수 기준으로 집계하도록 변경하여, 머신 케이싱, 가열 코일, 해치, 버스, 컨트롤러 등 고가 자재가 자재 청구서(BOM)에서 중복 카운트되는 문제를 해결했습니다.
  - `MultiblockBOMSummary` 및 `MultiblockStructurePart` 도메인 모델을 도입하여 일반 레시피 원자재와 구조체 블록 소요량을 명확히 분리하고, 다국어 블록 명칭과 필요 수량을 직관적으로 렌더링합니다.
- **EMI 아이템 툴팁 깊이 버퍼(Z-Index) 충돌 및 관통 결함 수정**:
  - EMI 슬롯 위젯의 3D 아이템 모델 렌더링 후 잔류한 깊이 버퍼(Depth Buffer)로 인해 툴팁 배경 사각형과 텍스트가 뚫리거나 배경 아이템이 툴팁 박스를 뚫고 전면에 돌출되던 Z-fighting 버그를 해결했습니다. `BoardTooltipRenderer`에서 툴팁 렌더링 직전 드로우콜 플러시(`graphics.flush()`), 깊이 버퍼 명시적 클리어(`GL11.GL_DEPTH_BUFFER_BIT`), Depth Test 비활성화 및 Z축 변환(`+1000.0f`)을 적용하여 툴팁이 최상단에 안정적으로 렌더링되도록 보장했습니다.
- **튜토리얼 단계 전환 시 기계 설정 버튼 발광 및 조작 안정성 개선**:
  - `TutorialManager`에서 머신 설정 단계 진입 시 설정 버튼 발광 표시 및 단계 완료 판정이 정상 동작하도록 개선했습니다.
- **원료 결핍 및 가동 효율 저하 시 분기점 목표 소요 시간(ET) 및 배치 총 전력 연산 왜곡 수정 (`ProductionETACalculator`)**:
  - 원자재 공급 부족으로 상류/하류 기계의 가동 효율(`getEfficiency()`)이 100% 미만으로 떨어져 있거나 비가동(`!isOperational()`) 상태일 때, 기존 연산기가 이를 반영하지 않고 이론상 최대 생산 속도(100% 가동률)로 계산하여 목표 배치 소요 시간(ET)이 비현실적으로 짧게 표시되거나 총 전력(EU) 소모량이 왜곡되던 문제를 수정했습니다.
  - 실제 기계 효율과 유효 가동 여부를 상류 공급 유량(`calculateNetInflowRate`), 하류 소비 유량(`calculateNetOutflowRate`), 배치 총 전력 소비량(`calculateTotalEnergyForBatch`)에 직접 곱하여 반영함으로써, 공급 병목(Supply Bottleneck) 발생 시 실제 감소된 생산율에 비례하여 ET가 정확히 연장 계산되도록 정합성을 보장했습니다.
- **분기점 노드 외부 공급 설정 창 고정 유량 입력 상자 클릭 및 라벨 겹침 결함 수정 (`JunctionSupplyDialog`)**:
  - 라디오 버튼 행의 클릭 히트박스가 우측 `고정 외부 공급 유량(Fixed External Supply Rate)` 입력 상자 전체를 덮어씌워 텍스트 필드를 클릭해도 포커스를 획득하지 못하고 키보드 입력이 차단되던 결함을 수정했습니다.
  - 다이얼로그 가로 폭을 260px에서 300px로 확장하여 영어 및 다국어 환경에서 라벨 문자열과 텍스트 박스가 서로 겹치던 UI 글자 잘림을 수정하고, 고정 유량 라디오 옵션을 선택했을 때 텍스트 박스에 자동으로 포커스가 들어가도록 인터랙션을 개선했습니다.
- **외부 공급 정션 노드의 소요 시간(ET/DT) 오분류 및 유량 연산 결함 수정 (`ProductionETACalculator`, `NodeCardRenderer`)**:
  - 외부 공급(고정 유량 또는 무한 공급 ∞)이 지정된 분기점 노드에 상류 입력 와이어가 연결되어 있지 않을 때, 외부 공급원임에도 불구하고 미연결 원자재 버퍼(`isInputSourceJunction`, Unconnected Raw Input)로 오인되어 목표 생산 완료 시간(`ET`) 대신 재고 고갈 시간(`DT`)으로 잘못 계산 및 표시되던 결함을 수정했습니다.
  - `calculateNetInflowRate`에서 노드 자체의 외부 공급 유량을 인식하지 못해 0.0으로 반환하던 문제를 해결하여, 정션 노드의 ET 계산뿐만 아니라 하류 기계 노드로의 유입 유량이 정상 전달되도록 수정했습니다.
- **분기점 호버 툴팁 소비 유량 및 고갈 소요 시간 수치 불일치 해결 (`BoardTooltipRenderer`)**:
  - 정션 툴팁에 표시되는 소비 유량(`Drain Rate`)이 기계 가동 효율(예: 50%)을 반영하지 않은 이론상 최대 수요(-62 mB/s)로 표시되던 반면, 실제 고갈 시간(`Depletion Time`)은 가동 효율이 반영된 유량(30.86 mB/s)으로 나누어 계산되어 툴팁 수치 간 모순(1,000 / 62 = 16.1s가 아닌 32.4s)이 발생하던 문제를 해결하고, 실제 유출 유량(`calculateNetOutflowRate`)과 일치하도록 동기화했습니다.
- **외부 공급 노드 카드 뱃지의 유체 단위 표기 보정 (`NodeCardRenderer`)**:
  - 분기점 노드 상단에 렌더링되는 외부 공급 뱃지가 유체 여부(`isFluid()`)를 감지하지 못하고 아이템 단위(`/s`)로만 출력되던 결함을 수정하여 유체일 경우 `mB/s`로 올바르게 표시되도록 보정했습니다.
- **이산 기계 사이클(Discrete Cycle) 부동소수점 오차로 인한 소요 시간(ET/DT) 2배 뻥튀기 결함 수정 (`ProductionETACalculator`)**:
  - 기계의 사이클 주기(예: 16.2초)와 목표 배치 수량(예: 1회 가동 생산량인 1,000 mB)이 정확히 정수 배로 일치함에도 불구하고, 부동소수점 배정밀도 나눗셈 오차((1000.0 / 16.2) * 16.2 = 999.9999999999999 mB)로 인해 필요 사이클 수 계산 시 1.0000000000000002가 산출되어 `Math.ceil` 올림에 의해 1회 가동(16.2초) 대신 2회 가동(32.4초, 62 mB/s * 32.4s = 2008 mB)으로 계산되던 심각한 수치 왜곡 결함을 수정했습니다.
  - `calculateETA` 및 `calculateDepletionTime`의 사이클 올림 계산식에 부동소수점 오차 허용 입실론(1e-7) 가드를 적용하여 단일 사이클 생산 배치 수량이 정확한 소요 시간(16.2초) 및 일치된 총 전력(311k EU)으로 계산되도록 보장했습니다.

## [2.1.0-beta.2] - 2026-09-04

### 신규 기능 (Added)
- **와이어 유량 포화도 기반 애니메이션 및 실시간 공정 병목 시각화**:
  - 계산기 캔버스의 연결선(Wire)에 원료 공급 포화율(포화도 = 공급량 / 수요량)을 반영한 동적 흐름 애니메이션을 적용했습니다. 원료가 충분히 공급될 때는 시안 블루(Cyan Blue) 색상으로 매끄럽게 주행하며, 부분 결핍 시 호박색(Amber Orange)으로 감속 및 간헐적 정지(Stutter)하고, 심각한 결핍 시 진홍색(Crimson Red)으로 지연됩니다.
  - 원료 공급 부족으로 가동률이 저하된 기계 노드 카드 외곽에 호박색 펄스 글로우(Amber Pulse)가 표시되어 복잡한 공정표에서도 병목 기계를 즉시 식별할 수 있습니다.
  - 환경설정(`[⚙ 환경설정]`)에서 와이어 흐름 애니메이션을 3단계(`포화도 연동`, `단순 펄스`, `비활성화`)로 자유롭게 전환할 수 있습니다.
- **잉여 부산물 폐기 처리 및 보이드 싱크 시스템**:
  - **보이드 정션 노드 (`SupplyMode.VOID_SINK`)**: 중계 정션(Reroute Node)의 공급 모드에 '보이드 싱크'를 추가하여 배관망으로 유입되는 잉여 부산물을 무한히 흡수 및 소각 처리할 수 있습니다. 1:N 분기 연결 시 정상 소비 기계의 실수요를 1순위로 충족한 후 남은 잔여 잉여분만 흡수하여 하류 공정 굶주림을 원천 차단합니다.
  - **포트 단위 직접 보이드 마킹**: 기계 카드의 출력 포트를 `Alt + 우클릭`하여 배관을 단절하지 않고도 특정 부산물 출력을 최종 결산에서 손쉽게 제외할 수 있습니다.
  - **요약 결산창 원클릭 보이드 및 접이식 복원**: 우측 결산창(`SummaryOverlay`)의 순 생산품 목록에서 `[🗑]` 버튼을 클릭하여 즉시 폐기 목록으로 이동할 수 있으며, 접이식 `🗑 폐기된 부산물` 섹션에서 수량 확인 및 `[↩]` 원클릭 복원을 지원합니다.

### 개선 및 변경 (Changed & Improved)
- **보이드 및 병목 관련 캔버스 시각적 피드백 강화**:
  - 보이드 싱크 정션 노드에 보라색 외곽선과 `VOID` 배지를 부착하고, 보이드 지정된 출력 포트를 보라색 라벨과 소켓 테두리로 강조 렌더링합니다.
  - 포트 호버 툴팁에 현재 원료 충족률(%)과 보이드 상태 안내 라벨 및 `[Alt+우클릭]: 보이드 처리 토글` 단축키 가이드를 추가했습니다.
- **Systeams 증기 유체 표시 단위 및 명칭 가독성 개선**:
  - Systeams 다단계 보일러에서 생산되는 증기 유체에 대해 mB/s 또는 B/s 축약 단위를 자동 적용하고, 실제 등록된 유체 설명 이름(Warm Steam, Hot Steam, Superhot Steam 등)이 정상 표시되도록 개선했습니다.

### 버그 수정 (Fixed)
- **GTCEu 고전압 오버클록 시 싱글블록 1틱 미만 연산 왜곡 수정**:
  - 싱글블록 기계가 고전압 오버클록으로 인해 레시피 소요 시간이 1틱(0.05초) 미만으로 단축될 때, 서브틱 병렬을 지원하지 않는 싱글블록 특성에 맞추어 1틱에서 오버클럭을 조기 종료(Early Break)하도록 수정하여 EU/t 전력 소모량이 비정상적으로 폭증하거나 연산이 왜곡되던 문제를 해결했습니다. (멀티블록 기계는 1틱 도달 후에도 서브틱 병렬을 정상 유지합니다)
- **Systeams 보일러 유체 ID 및 레시피 매니저 리플렉션 호환성 수정**:

## [2.1.0-alpha.2] - 2026-08-31

### 신규 기능 (Added)
- **공유 기계 풀 (Shared Machine Pool 프레임)**:
  - 단일 물리 기계(예: 커터, 화학 반응기, 원심분리기 등)가 여러 레시피를 시간 분할 공유(Time-Sharing Duty Cycle)하는 공정을 모델링할 수 있는 공유 기계 풀 프레임 추가.
  - 풀 내부 레시피들의 총 분담률(`Total Duty %`)과 올림(`Ceil`) 필요 기계 대수를 실시간 계산하여 프레임 헤더 배지 및 상세 Breakdown 툴팁 제공.
  - 프레임 헤더의 `[⚙ 설정]` 버튼으로 내부 모든 기계의 전압 티어, 오버클럭 모드, 병렬 수, 장착 애드온을 일괄 동기화.
  - 멀티블록 BOM 계산 시 공유 기계 풀에 속한 기계 구조체들이 중복 집계되지 않고 실제 필요한 기계 세트 수만 정확히 반영.
- **포트 다중 선택 & 번들 일괄 배선 UX (Port Multi-Selection & Bundle Batch Wiring)**:
  - 마키 포트 선택: 카드 면적의 35% 미만을 침범하도록 마키 영역을 드래그하여 특정 입출력 포트들만 조건부 다중 선택.
  - 탐색기 방식 다중 선택: `Ctrl + 클릭`으로 개별 포트 토글, `Shift + 클릭`으로 포트 연속 범위 일괄 선택.
  - 실시간 다중 번들 와이어 드래그: 다중 선택된 포트들로부터 마우스 커서로 모여드는 다중 베지어 번들 곡선 실시간 렌더링.
  - 빈 캔버스에 드롭 시 세로 정렬된 분기점(Junction) 노드 자동 생성 및 1:1 배선.
  - 공유 기계 풀에 번들 드롭 시 일치 기계 자동 배선, 미배치 레시피 자동 검색/생성/배치, 풀 하드웨어 동기화, 프레임 바운딩 박스 자동 확장을 일괄 처리.
  - 보조 투입 재료 우선 일치 탐색: 머신 풀에 새 레시피 자동 생성 시 풀 내부 대표 기계가 사용하는 보조 투입물(예: 윤활유 vs 물)과 일치하는 레시피를 우선순위 기반으로 자동 매칭.
  - `Shift + 드롭` 시 각 레시피의 생산량에 맞춘 소수점 가동 대수(Duty) 1:1 Auto-Ratio 지원.
  - 프레임 헤더 `[⛶ 크기 맞춤]` 액션 버튼 및 헤더 더블클릭 자동 맞춤 지원.
