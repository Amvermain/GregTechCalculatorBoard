## 🎮 2단계: 5분 실전 인게임 스모크 테스트 (릴리즈 후보 프로토콜)

배포 직전 테스트 월드에서 다음 12개 핵심 사용자 경험을 수동으로 점검합니다:

### 1. 캔버스 렌더링 & 뷰포트 조작
- [ ] **보드 오픈 및 화면 맞춤**: `B` 키로 보드 화면 진입 후 `Home` 또는 `F` 입력 시 모든 노드가 화면 중앙에 완벽히 정렬되는지 확인.
- [ ] **팬 & 줌 부드러움**: 마우스 우클릭 드래그 시 부드러운 팬 이동, 휠 스크롤로 $25\% \sim 200\%$ 줌 시 폰트 깨짐이나 위젯 번짐이 없는지 확인.
- [ ] **Scissor 클리핑 가드**: 서브페이지 모듈이나 모달 다이얼로그 오픈 시 컴포넌트가 뷰포트 테두리 밖으로 삐져나오지 않는지 확인.

### 2. 인터랙티브 와이어링 & 핵심 FSM
- [ ] **스플라인 와이어 연결**: 초록색 출력 포트 $\rightarrow$ 파란색 입력 포트 클릭 시 수급 포화도 색상으로 매끄럽게 연결되는지 확인.
- [ ] **Shift + 자동 비율 맞춤**: `Shift`를 누른 채 두 기계를 연결할 때 대상 소비 기계 대수가 1:1 공급량에 맞춰 자동으로 비례 역산되는지 확인.
- [ ] **와이어 더블클릭 분기점 생성**: 기존 와이어를 더블클릭하여 비용 0의 [🔀 분기점 노드]가 즉시 삽입되고 유량이 정상 분배되는지 확인.
- [ ] **와이어 절단**: 연결선 위나 연결된 소켓 포트를 우클릭하여 즉시 절단되는지 확인.
- [ ] **포트 드래그 빈 공간 검색**: 포트에서 빈 캔버스로 드래그 시 4버튼 퀵 마커가 생성되고, 레시피 검색창이 해당 재료 필터로 자동 열리는지 확인.

### 3. 다이얼로그, 모달 & 단축키 격리
- [ ] **LIFO 모달 닫기 순서**: 기계 설정창 $\rightarrow$ 레시피 전환기 순차 오픈 후 `ESC` 입력 시 최상위 다이얼로그만 먼저 닫히는지 확인.
- [ ] **키 입력 누수 방어**: 텍스트 입력창(`EditBox`, 기계 대수 수정, 이름 변경)에서 타이핑 중 마인크래프트 기본 키(`E`, `Space`, `W/A/S/D`)를 눌러도 보드가 닫히거나 캔버스 단축키가 가로채지지 않는지 확인.

### 4. 히스토리 스택 & 세이브 영속화
- [ ] **실행 취소/다시 실행 무결성**: 노드 이동, 와이어 절단, 레시피 교체 후 `Ctrl + Z` 및 `Ctrl + Y` 시 정확한 위치와 와이어가 유령 노드 없이 100% 복원되는지 확인.
- [ ] **월드 저장 및 재접속**: 복합 공정 배치 후 월드 저장 $\rightarrow$ 메인 메뉴 나갔다 재접속 시 보드 배치, 커스텀 이름, 유량 계산 결과가 100% 동일하게 로드되는지 확인.
- [ ] **블루프린트 클립보드 공유**: `Share` 클릭(Base64 복사) $\rightarrow$ 다른 페이지에서 `Import` 시 동일한 팩토리가 완벽히 복원되는지 확인.

### 5. 데디케이티드 서버 & 멀티플레이어 안전성
- [ ] **데디케이티드 서버 단독 기동**: 모드가 설치된 전용 서버 구동 시 **`NoClassDefFoundError`나 클라이언트 클래스로딩 크래시 없이 정상 기동**되는지 확인.
- [ ] **멀티플레이어 실시간 동기화**: 2명 이상의 클라이언트 접속 시 팀 보드 편집 내역, 노드 락 점유, 커밋 로그가 레이스 컨디션 없이 매끄럽게 동기화되는지 확인.
