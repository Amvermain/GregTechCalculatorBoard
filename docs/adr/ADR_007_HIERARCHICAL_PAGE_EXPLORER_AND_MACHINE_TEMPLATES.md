## 1. 배경 및 동기 (Context)

대규모 멀티블록 공정과 복합 생산 체인을 설계할 때 페이지 수가 10~40개 이상으로 증가하면서 기존 단일 가로 탭 바(`PageTabBarWidget`) 구조로는 다음과 같은 한계가 발생했습니다:
1. **탐색 피로도**: 선형 1열 탭 바로는 수십 개의 페이지 사이를 이동하기 위해 좌우로 끝없이 스크롤해야 함.
2. **카테고리 부재**: 금속 제련, 석유화학, 회로 조립 등 상이한 공정들이 단일 리스트에 무작위로 혼재됨.
3. **기계 세팅 반복 피로**: 동일한 하드웨어 스펙(EV 4x 칸탈 EBF 등)으로 다수의 레시피 페이지를 생성할 때 티어, 전압, 코일, 병렬 수치를 매번 수동으로 재설정해야 함.

---

## 2. 의사 결정 (Decision)

### 2.1 도메인 모델 확장 (`BoardPage` & `MachineHardwareTemplate`)
- `BoardPage`에 `folderPath`, `representativeIcon`, `isPinned`, `isFolderCollapsed` 속성을 추가하고, NBT 직렬화 및 하위 호환성을 보장하도록 확장했습니다.
- `MachineHardwareTemplate` 순수 도메인 모델을 도입하여 기계 하드웨어 스펙(`machineId`, `voltageTier`, `overclockMode`, `parallelLimit`, `steamMode`, `isMultiblock`, `properties`, `addons`)을 캡슐화하고, `applyToRecipe()`를 통해 새 레시피에 동일 하드웨어 구성을 100% 주입할 수 있도록 설계했습니다.

### 2.2 클라이언트 UI 컴포넌트 구조
1. **`PageBrowserDrawer` (슬라이드 오버 사이드바 탐색기)**:
   - 좌측 슬라이드 아웃 드로어(너비 230px, Z-Order 400.0f).
   - 다층 폴더 트리(접기/펼치기), 실시간 필터링, 상단 탭 핀 고정 토글(`📌`), 활성 페이지 하이라이트.
   - 컨텍스트 메뉴(이름 변경, 핀 토글, 하드웨어 복제&레시피 교체, 폴더 삭제 등) 및 드래그 앤 드롭 폴더 이동 지원.
   - 드로어 외부 클릭 시 자동 닫힘(Click-Outside Dismiss) 및 기존 FavoritesDock 상태 100% 보존.
2. **`QuickPageSwitcherDialog` (Ctrl+K / Ctrl+P 실시간 점프 모달)**:
   - 키보드 중심의 빠른 페이지/폴더 퍼지 검색 팝업.
   - `↑`/`↓` 탐색 및 `Enter` 즉시 전환 지원.
3. **`TemplateCloneDialog` (하드웨어 보존 레시피 교체 모달)**:
   - 기존 페이지의 기계 하드웨어 설정을 기반으로 전역 레시피 목록에서 새 레시피를 검색/선택하여 원클릭으로 신규 페이지 생성.

### 2.3 단축키 및 컨트롤 바 통합
- `Tab`: 페이지 브라우저 드로어 열기/닫기 토글.
- `Ctrl + K` / `Ctrl + P`: 빠른 페이지 점프 팝업 열기.
- 상단 탭 바 좌측에 `[ 📑 ]` 브라우저 열기 버튼 및 핀 고정 아이콘(`📌`) 연동.
- 상단 탭 우클릭 / Shift+우클릭 시 하드웨어 복제 및 이름 변경 지원.

---

## 3. 결과 및 영향 (Consequences)

### 3.1 긍정적 효과
- **대규모 공정 관리 효율 극대화**: 30~50개 이상의 페이지도 폴더 트리와 빠른 검색(`Ctrl+K`)을 통해 즉각 탐색 가능.
- **반복 세팅 작업 90% 단축**: 템플릿 복제를 통해 동일 하드웨어 공정 라인을 1초 만에 연속 생성 가능.
- **도메인 순수성 및 SPI 원칙 준수**: `MachineHardwareTemplate`과 `BoardPage`는 특정 모드에 종속되지 않는 순수 도메인 모델로 설계되어 모듈 분리 원칙을 완벽히 준수.

### 3.2 데이터 구조 및 NBT 호환성
- 기존에 저장된 `BoardPage` NBT 데이터에 신규 태그가 없는 경우 기본값(`folderPath=""`, `isPinned=true`, `isFolderCollapsed=false`)으로 자동 폴백되어 이전 버전 저장 데이터와 100% 양방향 호환됩니다.
